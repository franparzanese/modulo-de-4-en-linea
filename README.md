# Módulo de 4 en línea

## Objetivo

Desarrollar un módulo para el juego 4 en línea similar a un módulo de ajedrez: dado un estado de una partida, debe determinar si uno de los jugadores puede o no forzar la victoria (es decir, ganar independientemente de lo que juegue el oponente). En caso que sí, debe indicar la cantidad de jugadas para forzar la victoria y la secuencia de columnas donde el jugador debe ir colocando sus fichas.

## Objetivos de aprendizaje

* Desarrollo de un proyecto en C.
* Implementación de tests en C, incorporando algún framework de testing.
* Makefile: generará los ejecutables del proyecto y de pruebas.
* GitHub Actions: ejecutará las pruebas ante cada commit.
